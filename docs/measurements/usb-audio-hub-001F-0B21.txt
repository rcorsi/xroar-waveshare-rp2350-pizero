USB audio in a 4-port USB-C hub with a headphone jack (PIZERO-255 spike, 2026-10-23)

Hub: Genesys Logic GL850G, VID 05E3 PID 0608, 4 ports. The audio chip below
appears on hub port 3 only while a plug is in the headphone jack.

Captured with the pizero_usbdump env ([usbdesc] lines; TinyUSB host log at
level 2 for the raw bytes). Full speed. Configuration descriptor, 423 bytes,
which is over TinyUSB's default 256-byte enumeration buffer.

Decoded:
  AC header UAC2. Clock sources 9 (playback) and 10 (capture), internal
  programmable (bmAttributes 07). Feature unit 2 (playback): master mute,
  volume per channel.
  Interface 1 (playback, terminal 1, stereo):
    alt 1: 24-bit (subslot 3), EP 03 OUT isochronous synchronous, 288 bytes
    alt 2: 16-bit (subslot 2), EP 03 OUT isochronous synchronous, 192 bytes
           = 48 samples x 2 channels x 2 bytes: 48 kHz
  Interface 2 (capture, mono): alt 1 16-bit 96 bytes, alt 2 24-bit 144 bytes,
    EP 83 IN isochronous synchronous.
  Interfaces 3 and 4: HID, interrupt IN 81 and 82 (likely the volume keys).
