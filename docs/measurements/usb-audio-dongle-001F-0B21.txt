USB-C headphone dongle (PIZERO-255 spike, 2026-10-23)

Plugged into a USB-C port of the GL850G hub, headphones in. Captured with the
pizero_usbdump env. Full speed. Configuration descriptor 218 bytes (fits
TinyUSB's default 256-byte enumeration buffer).

VID 001F PID 0B21: the same IDs as the audio chip in the hub
(usb-audio-hub-001F-0B21.txt), but this one is USB Audio Class 1.

Decoded:
  AC header UAC1.
  Interface 1 (playback): alt 1 = PCM, 2 channels, 16-bit (subframe 2),
    48,000 Hz only; EP 03 OUT isochronous ADAPTIVE, max 384 bytes, interval 1.
    48 kHz stereo 16-bit is 192 bytes a frame.
  Interface 2 (capture): alt 1 = mono 16-bit 48 kHz, EP 83 IN isochronous
    async, max 208 bytes.
  Interface 3: HID, interrupt IN 82 (the volume keys).

Against the hub's chip: both take 16-bit stereo 48 kHz on isochronous OUT
EP 03 with no feedback endpoint, so one driver sends 48 sample pairs a frame
to either. Only the setup differs: UAC1 sets the rate with an endpoint
SAMPLING_FREQ SET_CUR and mute/volume through its feature unit; UAC2 with
the clock source's CUR and the UAC2 feature unit.
